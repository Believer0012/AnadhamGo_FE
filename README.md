# Aanandham.go — Luxury Wilderness Platform

A modern Next.js web platform for **Aanandham.go** featuring high-altitude mountain glamping, 4x4 sunrise peak safaris, starlit campfire gatherings, and guided tea ridge treks across Suryanelli & Munnar, Kerala.

## ✨ Features
- **Hero & Camp Overview**: Immersive typography with Bricolage Grotesque & Plus Jakarta Sans, live badge indicators, and atmospheric photography.
- **Skill Levels**: Interactive skill cards with active badge states.
- **Camp Program**: Interactive floating cursor-following preview cards for morning, afternoon, and night programs.
- **Nearby Attractions & Peaks**: Detailed guide to Kolukkumalai, Phantom Head, Anaerangal Lake, Lockhart Gap, and Chinnakanal.
- **Authentication**: Seamless sliding-panel swap physics between **Log In** and **Create Account / Join Tribe**.
- **Contact & Booking Intake**: WhatsApp and email integrations with embedded Suryanelli coordinate map.
- **Single-Letter Interactive Watermark**: Dynamic letter hover elevation and ambient glow.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
